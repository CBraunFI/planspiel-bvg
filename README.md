# Planspiel BVG – Hot-Seat-Prototyp

Entwicklungsstand des Planspiels für das JUMP-Programm (SYNK / Leada). Dieses Repository enthält den spielbaren Prototyp als eine einzige HTML-Seite, die Stilprobe und das Spielleitungs-Heft.

- `index.html` – Simulator (Regelstand v2.5, Dilemma-Modus): eine Person spielt alle vier Rollen und die Spielleitung. Protokoll, Auto-Sim zum Balancing und alle Regelschalter sind hinter dem Zahnrad.
- `stilprobe.html` – Stilprobe für Oberfläche, Portraits und Piktogramme.
- `docs/Spielleitungsheft_v1.md` – Szenario, Rollen, Regeln, alle 31 Karten mit Vorlesetexten.

Zum Review: Seite öffnen, Figuren wählen, „Spiel starten“. Der Timer pro Zug (60 s) lässt sich unter „Regeln anpassen“ abschalten.

Alles in dieser Fassung ist Arbeitsstand, kein Kundenmaterial.
